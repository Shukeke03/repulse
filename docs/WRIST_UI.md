# 腕端界面说明

启动项目后，打开 [腕端显示预览](http://127.0.0.1:8765/#/wrist)，或从左侧导航进入。它是独立的第九个页面，用浏览器模拟 240×280 像素圆角屏幕、四个实体按键和腕表外壳。页面左侧显示腕端结构，右侧显示按键说明和最近八次输入结果；窄屏下说明区移到腕表下方，并增加文字按键。

当前界面运行在浏览器中。页面标注的 1.69 英寸 IPS 是预览的设计规格，浏览器缩放后的显示尺寸不表示实际屏幕尺寸；项目尚未接入物理屏幕、按键或振动器。

## 按键与页面导航

| 按键 | 键盘 | 操作 |
| --- | --- | --- |
| 返回 | `Esc` | 短按返回上一级；长按约 0.8 秒回到表盘。设置存在未保存修改时，返回会先询问是否放弃。 |
| 上 | `↑` | 上一项或上一页；按住约 0.45 秒后连续移动。 |
| 下 | `↓` | 下一项或下一页；按住约 0.45 秒后连续移动。 |
| 确认 | `Enter` | 进入选中项、选择数值或执行操作；在腕端恢复过程页中长按约 1.2 秒打开停止演示的确认页。 |

确认与返回短按在松开时触发，上下键在按下时触发。屏幕超过设置的亮屏时长后调暗，第一次按键只唤醒屏幕，第二次才执行操作。表盘按确认进入菜单，按下进入恢复过程，按上进入记录库。页面结构栏允许直接跳转和查看当前位置，便于在电脑上检查各页。

停止演示和删除记录均有二次确认，默认选中保留或继续选项。窗口结果、恢复起点和处理结束等事件会显示提示并点亮屏幕；腕表外壳的抖动动画表示模拟振动。

## 八个腕端应用

| 应用 | 可执行操作与显示内容 |
| --- | --- |
| 新建演示 | 选择公开记录、Python 或可用的 FreeRTOS / QEMU 路径、读取策略、周期偏移和演示速度，然后启动处理。同一时刻只允许一次演示。 |
| 恢复过程 | 上下键循环查看实时脉率、最近 8 秒脉搏波与运动变化、0/60/120 秒关键窗口、读取计划和最近五条处理事件；确认打开操作菜单，可切换原始/滤波后波形、查看起点说明或停止演示。 |
| 记录库 | 查看最近 20 条公开数据处理记录，进入窗口结果和配置详情；已结束记录可回放或删除。 |
| 记录回放 | 从最近 20 条记录中筛选已结束记录；上下键选择回到开头、后退 10 秒、播放/暂停、前进 1 秒或切换速度，确认执行。逐秒前进要求先暂停。 |
| 策略比较 | 对选中记录运行三种策略与 0、5、10、15 秒四个偏移的比较，查看进度、窗口可用率和平均读取时长，也可停止比较。 |
| 数据与片段 | 查看已下载数据及来源信息；在详情中切换起点、60 秒、120 秒窗口或完整片段的波形预览，可用该记录新建演示。 |
| 系统状态 | 查看系统概览、处理任务和关于本机三个页面。任务信息来自本机服务；QEMU 任务仅在相应固件会话运行时可用。 |
| 设置 | 修改亮屏时长、界面刷新频率、电脑端图表时长和新演示默认策略，保存后写入本机服务；亮度立即生效并仅保存在当前浏览器。 |

## 与电脑端共享的数据

`app.js` 创建一个 `WristOS` 实例，并向它提供同一份实时会话、连接状态、设置和本机 API。腕端启动或停止演示，会影响电脑端显示的同一次演示；腕端删除记录，也会删除同一份本地处理归档。恢复过程页右栏显示该腕端实例的镜像，按键操作集中在腕端预览页。电脑端冻结视图时，图表、指标、窗口与事件固定在冻结时刻，腕端镜像继续显示最新状态，页面会提示这一点。

离开腕端预览或恢复过程页时，腕端绘制和页面轮询暂停，后台演示、策略比较继续由本机服务执行。腕端页面栈保留，返回时继续显示原页面；离开腕端回放时关闭对应回放连接，原始处理记录保持不变。腕端设置中保存的默认策略用于之后新建的演示，当前演示仍使用创建时的配置。

## 绘图结构与固件移植边界

`web/js/wrist.js` 将实现分为以下部分：

- `PANEL` 固定 240×280 像素坐标，`Gfx` 封装矩形、圆角矩形、圆弧、文字、图标、折线和裁剪等绘图原语。
- `SCREENS` 定义表盘、菜单、八个应用及选择、说明、确认等子页面；通用列表负责焦点、滚动和选中项。
- `WristOS` 管理页面栈、短按/长按/按住输入、亮屏、提示和刷新循环；显示数据按设置刷新，动画以 30 帧/秒为目标上限。
- `render()` 将页面和过渡、状态栏、提示合成到固定大小画布，`quantize()` 将像素颜色量化为 RGB565 精度，再输出到可见 Canvas。浏览器画布的底层存储仍为 RGBA，并未生成固件用的 RGB565 字节流。

后续移植可沿用页面结构、坐标、文案、按键事件和状态转换，将 `Gfx` 对应到屏幕驱动或固件图形库，并为页面提供固件内的数据与命令接口。当前代码仍使用 JavaScript、Canvas、浏览器字体、计时器、动画帧、HTTP/WebSocket 和 `localStorage`；这些依赖需要替换。屏幕驱动、中文字库、物理按键消抖与扫描、背光和振动驱动、内存及刷新性能尚未在 STM32 上实现或验证。

## 当前限制

- 腕端记录列表仅加载最近 20 条公开数据记录，没有分页或搜索；较早记录请使用电脑端记录库。
- 腕端记录详情不编辑备注或标签，也不导出文件；这些操作在电脑端记录库完成。
- 腕端数据预览使用服务端抽样后的波形，不逐像素显示完整片段的全部原始采样点；采样和算法计算仍使用原始记录。
- 预览复用本机公开历史数据和处理结果，不接收腕带实时传感器输入。FreeRTOS / QEMU 选项表示信号处理在固件中运行，腕端界面仍由浏览器绘制。
- 屏幕、亮屏和振动为界面模拟；未进行实体显示、物理按键、佩戴或临床准确度验证。
