# 算法与策略比较的实现约定

`backend/algorithms/processor.py` 只接收实际观测：ADC、加速度、时间、序号、区段和驱动故障。场景、注入计划和潜在脉率不进入算法；仅离线评估器使用真值。

滤波是100 Hz、0.5–5 Hz、两个二阶节的因果 Butterworth（SciPy `butter(2, ..., btype='bandpass')`）。状态跨数据块保持，物理断流或重新开启后从实际首样本重建并预热2秒。固定窗口为相对标记时刻 `[-4,4)`、`[56,64)`、`[116,124)`。任何窗口缺测都只沿自身依赖传播。光强接触阈值默认禁用；`LOW_AMPLITUDE` 是仿真 ADC 单位下的工程规则，并非已验证的人体接触检测。只有明确配置 `contact_threshold` 时才按该阈值输出 `NO_CONTACT`。

## 等预算的时间精度

周期策略为20秒周期，保留真正的周期区间，不在末尾拼补或截短来凑数字。每个整数相位0–19秒分别求解开启宽度，与观察区间 `[0,124)` 相交的**连续时间开启并集**精确为70秒。

实际输入每10毫秒一个采样点，`on_seconds` 根据真正开启的样本数除以100计算，保留量化差。例如相位5秒时是70.02秒，相位10秒时是70.01秒。每个策略运行输出 `budget_error_seconds=on_seconds-70`（连续策略不适用），并明确 `budget_quantization_tolerance_seconds=0.06` 秒。这是上述整数相位网格和100 Hz采样的离散计数容差，不是实机计时误差。能耗模型使用实际计数开启时长，准备阶段也计入；输出始终标记“估算”。

## 误差和错误有效率

所有三策略完整且具有相同输入哈希的种子/相位组才进入成对汇总。取消或失败的组列入排除数量，不能用不完整组比较。

每个关键窗口分别报告以下值；所有分母同时保存。分母为0时输出 `null`，界面应显示“--”。

- `same_window_error_bpm`：被算法接受的估计，相对同一窗口干净连续参考的绝对误差；没有可比较的有效估计时为缺测。
- `false_valid_rate`：错误接受数除以可评估窗口数。可评估指能够从真实观测明确判定缺口、预热不足、平线或截顶等无效，或者存在有效干净参考。错误接受指算法发布数值但窗口确定无效，或与干净参考的误差超过预设10 BPM。`false_valid_counts` 保存分子与分母。
- `deterministic_false_valid_rate`：只在上述确定性无效窗口中的错误接受比例；`deterministic_invalid_counts` 保存分母。
- `accepted_error_rate`：只在已接受且干净参考有效的结果中，绝对误差超过10 BPM的比例；`accepted_error_counts` 保存分子与分母。这一项确保噪声/同频干扰导致的错误有效结果不会被只看缺口的统计隐藏。
- 窗口可用率、两项变化量可用率与上述误差共同展示。全部拒绝不会成为高覆盖率结果。

合成数据仅验证工程流程、反例和调度，不用于证明真实人体或医学效果。
